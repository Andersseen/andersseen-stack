# create-andersseen-app

Reserved package for the future new-application creator.

Future command shape:

```bash
pnpm create andersseen-app
```

Its responsibility is to create complete Angular + Analog applications using Andersseen Stack defaults: signals, zoneless, strict TypeScript and Tailwind CSS 4.

This package intentionally does not include a wizard, templates, auth, database, billing, deploy providers or starter generators yet.
